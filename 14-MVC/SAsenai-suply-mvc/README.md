# SENAI Suply MVC - Especificação Inicial de Requisitos

## 1. Identificação

- Projeto: Senai Suply MVC
- Versão 1.0
- Estado: proposta inicial, sujeita a alterações
- Responsável: Equipe de Desenvolvimento I1D46B

## 2. Objetivos

Desenvolver uma aplicação web didátioca para consultar o catálogo de insumos insdustriais e acompanhar a quantidade em estoque, aplicando arquitetura MVC artesanal com PHP, Composer , PDO e PostgreSQL

## 3. Escopo

este projeto exibirá um painel de estoque, lista de insumpos, permitirá cadastrar novos itens e apresentar uma tela de login com autenticação de usuario.

### 3.1 partes interesadas e usuarios

- almoxarife: consultar o catalogo e cadastrar insumos
-gestor: acompanhar as quantidades agregadas no painel
- equipe de desenvolvimento: implementar e validar os requisitos do sistema

### 3.2 ambientes e dependencias

- PHP 8.3 ou superior, composer, extensão PDO para postgreSQL
- o banco de dados postgreSQL com o script schema.sql
-Servidor web configuradp
- navegador com suporte a HTML 5
